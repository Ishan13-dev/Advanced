# Ishan13 Websites 🚀

A modern, responsive, multi-page business website designed to showcase professional website development services, digital solutions, and business growth opportunities.

## 🌐 Live Demo

**Website:** [Visit Ishan13 Websites](https://advanced-lemon.vercel.app/)

## 📌 About the Project

Ishan13 Websites is a business website project created to present digital services through a clean, modern, and user-friendly interface.

The website highlights services such as website design, SEO optimization, and website maintenance. It also includes an image gallery, company information, and contact options to help visitors connect easily.

## ✨ Features

- **Home Page:** Attractive hero section with business introduction and call-to-action buttons.
- **About Page:** Information about the website and its purpose.
- **Services Page:** Showcase of available digital services.
- **Gallery Page:** Image gallery for visual presentation.
- **Contact Page:** Contact details and communication options.
- **Responsive Navigation:** Desktop and mobile navigation menus.
- **WhatsApp Integration:** Direct WhatsApp communication.
- **Call Integration:** Quick calling option.
- **Contact Form:** Interface for visitors to send messages.
- **Modern UI:** Gradient backgrounds, cards, shadows, and hover effects.
- **Google Maps Integration:** Embedded map section.

## 🚀 Run Locally

**Step 1: Clone the repository**

```bash
git clone https://github.com/Ishan13-dev/Advanced.git
```

**Step 2: Open the project folder**

```bash
cd Advanced
```

**Step 3: Run the website**

Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.

## 🌍 Deployment

This project is deployed using **Vercel**.

To deploy your own version:

1. Visit [Vercel](https://vercel.com/).
2. Sign in with your GitHub account.
3. Import the `Advanced` repository.
4. Configure the project settings.
5. Click Deploy.

Your website will be available through a Vercel deployment URL.
